# 🔓 Unlock My Answer

একটি মজাদার (Fun) এবং প্র্যাঙ্ক ধাঁচের ওয়েব প্রজেক্ট! এটি দেখতে সাধারণ ক্যালকুলেটর মনে হলেও, সঠিক উত্তর দেখার জন্য ব্যবহারকারীকে একটি ছোট মিশন সম্পন্ন করতে হয়। 

> **নোট:** এটি মূলত শেখা এবং বিনোদনের উদ্দেশ্যে বানানো একটি পার্সোনাল ফান্ড প্রজেক্ট। এতে কোনো ব্যাকএন্ড বা ডাটাবেজ ব্যবহার করা হয়নি।

---

## 💡 এটি কীভাবে কাজ করে?

1. এটি দেখতে একদম সাধারণ একটি ক্যালকুলেটরের মতো।
2. আপনি যেকোনো গাণিতিক হিসাব (যেমন: `2 + 2`) টাইপ করে `=` চাপবেন।
3. চাপার সাথে সাথেই স্ক্রিনে একটি **"Premium"** ধাঁচের ইন্টারফেস পপ-আপ করবে!
4. সেই ইন্টারফেসে একটি নির্দিষ্ট লেখা বা ইনপুট দিতে বলা হবে।
5. ব্যবহারকারী নির্দেশিত লেখাটি ঠিকভাবে ইনপুট দিলেই আসল উত্তরটি (যেমন: `4`) আনলক হবে এবং দেখা যাবে!

## 🛠️ ব্যবহৃত প্রযুক্তি (Tech Stack)

* **HTML5** - সাইটের মূল স্ট্রাকচার।
* **CSS3** - ডিজাইন ও রেসপন্সিভ লেআউট।
* **JavaScript** - ক্যালকুলেশনের লজিক ও পপ-আপ ইন্টারফেসের কাজ পরিচালনার জন্য।
* **Netlify** - প্রজেক্টটি ফ্রিতে লাইভ হোস্ট করার জন্য।
